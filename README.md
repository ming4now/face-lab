# 表情实验室 · Face Lab

使用电脑或手机前置摄像头驱动二维角色和三维人脸。

- 点击“开启摄像头”并授权即可使用；默认优先使用前置摄像头。
- 默认 480p、30 Hz 识别上限，优先 GPU，初始化失败自动尝试 CPU。
- 摄像头画面与表情识别在浏览器本机处理，不上传、不录制。
- 所有模型、WASM 和运行库随网站提供。

本仓库是可直接部署的静态网站，GitHub Pages 使用 `main` 分支根目录。
第三方模型与开源依赖的来源、许可见 [credits.html](./credits.html)。

本地预览：`python3 -m http.server 8765 --bind 127.0.0.1`，然后打开 `http://127.0.0.1:8765/`。摄像头需要 HTTPS 或 localhost。
